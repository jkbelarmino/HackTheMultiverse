# HackTheMultiverse 🌐💻
**An Unofficial Retro Cyber-Cinema Parody Mashup**

https://jkbelarmino.github.io/HackTheMultiverse

HackTheMultiverse is a single-file, interactive HTML5 web application inspired by 1990s “Hollywood OS” interfaces and retro cyber-sci-fi cinema.

Part retro cyberdeck, part interactive playground, and part gloriously unnecessary exercise in cinematic hacking, it combines terminal simulations, fictional computer systems, character-inspired experiences, HTML5 Canvas graphics, and Web Audio API synthesis into one browser-based multiverse.

**Why does it exist?** Because serious work gets exhausting, sometimes you need something fun to build, and apparently the reasonable response was to create an entire universe of fictional hacking interfaces. What started as a creative detour became a collection of interactive experiments, nostalgic references, unexpected rabbit holes, and questionable decisions involving terminals and pizza.

No actual mainframes were required. Gibson is doing its best.
